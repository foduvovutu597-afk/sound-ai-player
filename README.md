# RG-SOUND — плеер RAMIL GR

Плеер: https://foduvovutu597-afk.github.io/sound-ai-player/

## Как добавить трек
**Через браузер:** открой папку `audio` в репозитории → **Add file → Upload files** → перетащи файлы (mp3, m4a, wav, ogg, flac) → **Commit changes**.

**С компьютера (GitHub Desktop):** один раз клонируй репозиторий, например в `D:\AI\sound-ai-player`. Дальше кидай треки в папку `audio`, в GitHub Desktop нажми **Commit to main**, затем **Push origin**.

Название трека = имя файла (подчёркивания `_` станут пробелами). Например `Моя_песня.mp3` → «Моя песня».

## Как добавить обложку
Положи картинку (jpg, jpeg, png, webp) **с тем же именем**, что и трек, в папку `covers`: `audio/Моя песня.mp3` → `covers/Моя песня.jpg`.
Если обложки нет, берётся встроенная в файл обложка, а если и её нет — стандартная «RG-SOUND».

Изменения появятся в плеере через 1–2 минуты (обнови страницу). Удалить трек = удалить файл из `audio`.

## Избранное и метки
★ — избранное, кружок — цветная метка (зелёная → жёлтая → красная → нет). Сохраняются в браузере у каждого слушателя. Фильтры — в строке над списком: ★ Избранное, цвета и жанры (можно сочетать, строку можно листать вбок).

## Скачивание
⬇ у трека — скачать один трек. «Скачать выбранное» — скачать по очереди все треки, видимые с текущими фильтрами, в папку «Загрузки». Браузер может один раз спросить разрешение на скачивание нескольких файлов — нажми «Разрешить».
На iPhone «Скачать выбранное» показывает список кнопок — нажимай каждую, файлы попадут в «Файлы → Загрузки».

## Жанры
Подпапка в audio/ = жанр (например audio/Pop/песня.mp3). Файлы прямо в audio/ — «Без жанра». Чипы жанров сочетаются с ★ и цветами.

## Обновить песни
Кнопка «↻ Обновить песни» перечитывает список без перезагрузки страницы и не останавливает музыку.

## Режим владельца: переименовать и удалить треки
1. Открой https://github.com/settings/personal-access-tokens → **Generate new token** (Fine-grained).
2. Имя любое, срок — на выбор. **Repository access → Only select repositories → sound-ai-player**.
3. **Permissions → Repository permissions → Contents: Read and write**. Нажми **Generate token** и скопируй его.
4. В плеере нажми ⚙ (справа сверху) и вставь токен. Он хранится только в этом браузере и никуда не публикуется.
5. У каждого трека появятся ✎ (переименовать) и 🗑 (удалить). Изменения сразу коммитятся в репозиторий, на сайте — через 1–2 мин.
Чтобы выйти, снова нажми ⚙. Никому не передавай токен; если он утёк — удали его на той же странице GitHub.
